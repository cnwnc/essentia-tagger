# Top-level pins (what we actually depend on):
#   * essentia-tensorflow 2.1b6.dev1389 - newest release with a cp310 manylinux
#     wheel (2025-07). It ships the TensorflowPredictMAEST wrapper and bundles
#     a monolithic libtensorflow 2.5.0 built with CUDA *statically linked*

#   * numpy 1.26.4 - essentia's _essentia.so is built against the numpy 1.x
#     ABI; numpy 2.x breaks it.
#
# GPU dlopen requirements (all satisfied via LD_LIBRARY_PATH in flake.nix):
#   essentia's TF 2.5  -> libcudart.so.11.0, libcublas(+Lt).so.11,

#                         (+ libcurand.so.10 / libcusolver.so.11, which have
#                         identical sonames in the CUDA 12 wheels)
#   pip TF 2.19        -> CUDA 12 / cuDNN 9 sonames from the cu12 wheels
#   both               -> libcuda.so.1 from /run/opengl-driver/lib (NixOS)
